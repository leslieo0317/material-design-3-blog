# MD3 Personal Blog

一个适合部署在服务器上的轻量个人博客。技术栈是原生 PHP 8 + SQLite，不需要 Node 构建，也不需要单独安装 MySQL。

## 功能

- Android Material Design 3 风格首页、卡片、按钮、动效
- MD3 交互动效：波纹反馈、卡片展开、分项面板切换、平滑滚动
- 自动暗黑模式：跟随系统深色主题
- 首页右上角可手动切换明暗主题，并记住用户选择
- 后台 SEO 管理：浏览器站名、副标题、favicon、Logo 图标/URL、meta 描述、关键词和作者
- 后台全局配色：提供常见 MD3 配色方案
- 公告系统：首页弹窗公告，用户可关闭或标记已读不再提醒
- 注册页和修改资料页支持后台配置小提示语
- 多人注册/登录系统
- 用户组权限：管理员、博主、普通用户、封禁用户；后台可设置封禁天数、永久封禁和封禁理由
- 后台访问控制：可开关注册、全局评论、博客发布、博客审核和评论审核
- OIDC 登录配置：可在后台开启并配置登录按钮名称、Issuer、Client ID、Secret、回调地址
- OIDC 邮箱绑定：用户可在个人中心查看、绑定或解绑 OIDC 关联邮箱
- hCaptcha 配置：可分别为登录、注册、发布博客、评论开启验证码
- 邮件服务配置：支持邮箱验证和找回密码邮件入口
- Redis 缓存配置：安装 PHP Redis 扩展后可启用轻量缓存
- 首页头像、简介、其他网站链接展示，并可在后台管理首屏按钮，最多 6 个
- 博客列表、文章详情、楼中楼评论、文章点赞和评论点赞
- 搜索、收藏、关注和消息提醒：登录用户可搜索标题/作者、收藏博客、关注作者并接收回复/@ 提及提醒
- 独立博客页：按标签分组浏览文章
- 登录后右上角进入个人主页
- 独立发布/编辑博客页面：支持标签、首页固定、公开/隐藏/草稿、审核状态、封面 URL 或本地上传
- 个人头像支持 URL、上传和裁剪；注册时仅允许填写头像 URL
- Vditor Markdown 编辑器：标题、摘要、正文和评论均支持 Markdown，详情页使用 Vditor 渲染表格等内容
- 分项管理员后台：首页设置、友情链接添加、标签管理、文章/草稿/审核管理、评论管理、用户资料弹窗编辑、封禁/删号、版本信息

## 默认管理员

首次访问会自动创建管理员：

- 用户名：`admin`
- 密码：`admin123456`

上线后请立刻登录后台，在个人资料里更新头像和资料，并在修改资料页面更换默认密码。

## 宝塔部署

1. 在宝塔面板创建 PHP 网站，PHP 版本建议 8.0 或更高。
2. 确认 PHP 已启用 `pdo_sqlite` 和 `sqlite3` 扩展。
3. 上传本项目所有文件到网站根目录。
4. 确保 `data` 和 `uploads` 目录可写，权限建议 `755`，如果无法写入可临时设为 `775`。
5. 访问域名，系统会自动创建 `data/blog.sqlite`。

编辑器使用本地 Vditor 资源，文件位于 `assets/vendor/vditor/dist`。部署时需要一并上传 `assets/vendor/vditor` 目录。

## 目录说明

- `index.php`：主入口、页面渲染和路由
- `app/bootstrap.php`：数据库连接、自动建表、公共方法
- `app/actions.php`：登录、注册、发布、评论、点赞、后台保存等动作
- `assets/style.css`：MD3 风格界面
- `assets/app.js`：进入动画、提示条、高级编辑器交互
- `data/`：SQLite 数据库目录，部署后需要可写
- `uploads/`：封面图和头像上传目录，部署后需要可写

## 安全提醒

这个版本适合作为个人博客第一版。生产环境建议继续补充：文章 HTML 白名单更严格过滤、评论审核、HTTPS、定期备份 `data/blog.sqlite`。
